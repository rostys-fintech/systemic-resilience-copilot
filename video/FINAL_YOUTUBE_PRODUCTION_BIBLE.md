# 1. CREATIVE DIRECTION

The film must feel like a **premium institutional fintech product film** — not a screen recording with commentary, not a pitch deck, and not a research lecture.

Confidence comes from traceability, restraint and clarity.

## One-sentence film idea

**A backup can exist and still fail; the Copilot shows the first recovery condition that actually fails, the next justified action, and where evidence stops.**

## Tone

- calm authority;
- product-first;
- no hype / fear language / “AI magic”;
- no stock footage;
- no talking head;
- no code, terminal, research tables, manuscripts or equations;
- every visual change must make the decision path easier to understand.

---

# 2. SINGLE JUDGE JOURNEY

Use one causal chain only:

**Problem → Apertus extraction → deterministic decision → Apertus explanation → narrow fix → S6 UNKNOWN → systemic lens → S7 UNKNOWN → close**

Canonical proof path:

**95 min > 60 min → S5 RED / B2 → REPAIR_EXECUTION → 45 min → S6 UNKNOWN → S7 UNKNOWN**

The judge must understand:
1. backup existence is not executable recovery;
2. Apertus structures explicit facts from language;
3. deterministic rules set the state;
4. `UNKNOWN` is preserved;
5. one fix reveals the next evidence gap;
6. shared recovery exposure is not proof of a shortage.

# 4. OVERLAY DESIGN SYSTEM

Exactly **five major overlays maximum**:

1. **Backup exists ≠ executable recovery**
2. **95 min > 60 min → S5 RED · B2**
3. **AI explains. Rules decide.**
4. **95 → 45 → S6 UNKNOWN**
5. **Shared recovery resource ≠ proven shortage**

The close line `Evidence → Decision → Action` is an end card, not counted as an overlay.

## Styling

### Over dark hero
- warm bone plate / text;
- text: #F4EEE7;
- optional plate: navy/black at 45–58% opacity.

### Over light UI
- deep navy plate: #0F1B24 at 82–88% opacity;
- text: #F5F2ED;
- accent only for one metric/state, never multiple colors.

### Typography
- 42–50 px at 1080p;
- semibold / bold;
- one line where possible;
- max width 62% of frame;
- corner radius 16–20 px;
- 28–36 px horizontal padding.

### Motion
- 8–12 frame opacity + 8 px rise;
- 8–10 frame fade out;
- no bounce, typewriter, glow, glitch or kinetic typography.

---

# 5. TRANSITION SYSTEM

Use **three transition types only**.

### A. Clean cut
Use when logic changes state instantly:
- product → parse result;
- parse/rules → decision;
- explanation → fix.

### B. Match cut on click
Use when a user action causes the next state:
- parse button;
- Why?;
- Open systemic lens.

The cursor/button position should stay compositionally stable across the cut.

### C. Short dissolve
Use only:
- fade in from black at opening;
- systemic result → branded close.

No wipes, zoom transitions, whip pans, whooshes or preset transition packs.

---

# 6. CAMERA / SCREEN MOTION

Only editorial movement:
- 3–6% slow digital push;
- gentle pan toward current proof;
- deliberate cursor hover 0.4–0.6 s before important clicks;
- no more than one active camera idea per scene.

Never:
- zoom past 108% unless true higher-resolution capture supports it;
- circle the cursor;
- rapidly scroll;
- switch light/dark theme in film;
- place cursor over the text being read.

When a major overlay and captions appear together:
- major overlay lives in upper-left / upper-center safe zone;
- captions remain bottom-center;
- maintain at least 80 px vertical separation;
- if the UI proof occupies lower third, captions move upward to a designated middle-lower safe band rather than covering proof.
